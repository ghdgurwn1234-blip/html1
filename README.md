# (주)비에이텍 공식 웹사이트

유체 엔지니어링 솔루션 전문기업 (주)비에이텍 공식 웹페이지입니다.

## GitHub Pages 배포 방법

1. 이 저장소를 GitHub에 업로드
2. GitHub 저장소 → **Settings** → **Pages**
3. **Source**: `Deploy from a branch`
4. **Branch**: `main` / `(root)` 선택 후 **Save**
5. 잠시 후 `https://{유저명}.github.io/{저장소명}/` 으로 접속 가능

## 파일 구조

```
/
└── index.html   ← 메인 웹페이지 (단일 파일)
└── README.md
```
